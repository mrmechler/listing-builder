# ListingBuilder.com

A lightweight ListingBuilder homepage plus the first working tool, Story Builder.

## Routes

- `/` — intentionally simple ListingBuilder landing page while the full brand site is developed
- `/story/` — working 9:16 Instagram Story generator

## Story Builder includes

- 9:16 property photo upload
- Live 1080 × 1920 preview
- City, price, incentive, supporting line and CTA fields
- Exact logo file upload
- Agent name/title and phone fields
- Adjustable vertical photo position
- Client-side rendering
- One-click PNG download

## Deploy to GitHub Pages

1. Upload everything in this folder to the repository root.
2. Open GitHub **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select the main branch and `/ (root)`.
5. The included `CNAME` file points the site to `listingbuilder.com`.
6. Configure the appropriate GitHub Pages DNS records with the domain registrar.

Property photos and logos are rendered locally in the browser and are not uploaded by this static version.
